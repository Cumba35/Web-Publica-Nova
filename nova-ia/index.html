Nova IA

Proyecto de inteligencia artificial de Nova, con motor local Android y una plataforma de servicios en desarrollo.

Acerca del proyecto

La aplicación Android y el backend son componentes distintos. El servicio FastAPI no está desplegado en producción y la interfaz web administrativa no se publica aquí.

Alcance

  • Motor Android llama.cpp para importar y ejecutar modelos GGUF localmente en dispositivos compatibles
  • Historial local cifrado mediante Android Keystore
  • Herramientas matemáticas sin conexión, incluido cálculo científico y gráficas
  • Backend FastAPI con modelo SafeTensors como componente separado, todavía pendiente de despliegue de producción
  • Aprendizaje documental con fuentes fijadas y sin ejecutar código externo

Estado y límites

Esta página no es un chat activo. El backend administrativo no está aprobado para uso público: faltan autenticación multiusuario, controles de sesión y revisión de seguridad antes de exponerlo.

Esta página es la superficie informativa pública del proyecto. Las funciones autenticadas solo se habilitarán cuando el frontend, los servicios y sus controles hayan sido verificados.
