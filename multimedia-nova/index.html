Servicio privado para organizar archivos multimedia y conectar proveedores de almacenamiento autorizados.

Acerca del proyecto

El backend trabaja con almacenamiento privado, metadatos por usuario y enlaces temporales. Esta página no lista archivos ni solicita tokens OAuth.

Alcance

  • Catálogo unificado de archivos autorizados
  • Conectores OAuth cuando estén configurados
  • Almacenamiento privado con control por usuario

Estado y límites

No se publican buckets, objetos, tokens ni enlaces privados.

Esta página es la superficie informativa pública del proyecto. Las funciones autenticadas solo se habilitarán cuando el frontend, los servicios y sus controles hayan sido verificados.
