Multimedia Nova

Servicio privado para organizar archivos multimedia y conectar proveedores de almacenamiento autorizados.

Acerca del proyecto

La API de Multimedia Nova está desplegada en Railway. Ofrece un catálogo privado por usuario y conectores preparados para NOVA Storage, Google Drive y Dropbox; las credenciales OAuth de Google y Dropbox aún deben configurarse en el servidor.

Alcance

  • Almacenamiento privado NOVA con rutas por usuario y enlaces temporales
  • Google Drive: adaptador implementado, pendiente de credenciales OAuth y autorización individual
  • Dropbox: adaptador implementado, pendiente de credenciales OAuth y autorización individual
  • MEGA y MediaFire: deshabilitados hasta verificar API y permisos
  • Metadatos y tokens de proveedores protegidos en el backend

Estado y límites

La API responde en producción, pero las pruebas reales de carga y descarga autenticadas siguen pendientes. No se exponen buckets, objetos, tokens ni enlaces privados.

El panel de usuario está integrado en Nova Apps. Se requiere una sesión autenticada; esta página no permite consultar archivos de terceros.

La API de Multimedia Nova tiene una dirección de producción, pero el panel web no está publicado para usuarios. La interfaz se habilitará después de validar inicio de sesión, permisos y carga/descarga de archivos.
